# 条码工坊 (Goods Barcode Studio)

> **条码工坊**是一款本地优先、开箱即用的专业商品条形码生成、批量导出与标签排版打印桌面应用。基于 **Tauri 2 + Vue 3 + Vite + TypeScript** 构建，提供极速响应、极低内存占用与 100% 本地隐私安全保障。

---

## 核心特性

| 功能模块 | 说明 | 适用场景 |
| :--- | :--- | :--- |
| **官方条码制式** | Code 128、EAN-13（中国69码）、EAN-8、UPC-A | 商品零售、电商上架、仓储出入库、SKU管理 |
| **智能补全与核验** | 输入前 12 位自动计算并补齐校验位；输入 13 位自动合规核验 | 中国物品编码中心（GS1 China）分配条码 |
| **批量生成** | 单次支持 500+ 条，支持制表符/逗号/分号智能解析 | 批量商品建档、多品类快速生成 |
| **多格式批量导出** | **SVG 矢量图**、**PNG（1x/2x/4x 300DPI 超清）**、**JPG**、**WebP**、**SVG+PNG 合集** | 包装制版印刷、Word/Excel 插入、ERP 录入 |
| **批量保存方式** | 🗜️ **ZIP 压缩包**（含带 BOM 的 Excel CSV 与 JSON 清单）<br/>📁 **直接写本地文件夹**（免解压直接落盘） | 团队归档、设计交付、仓库快速分发 |

| **独立份数控制** | 为每个商品独立设置打印张数（`+` / `-` 步进器），支持一键统设 | 按入库批次数量批量打标贴标 |

## 详细功能介绍

### 1. 单条精细设计与批量生成
- **单个生成**：支持自定义商品名称、条码内容、制式、线条宽度（1 ~ 4px）、条码高度（50 ~ 160px）、线条/背景颜色，以及是否显示人工可读数字。
- **批量生成**：每行一条记录，支持 `商品名称,条码` 或仅填条码，支持表头自动跳过。
- **中国物品编码中心编码支持**：
  - 输入 12 位前缀+项目代码：系统自动以 Modulo 10 算法计算并补齐第 13 位校验码。
  - 输入 13 位完整编码：系统自动核验真伪与校验码准确性，杜绝印错包装。

### 2. 多格式批量导出系统
- **SVG (矢量格式)**：无限放大不失真，印刷制版、Illustrator / CorelDRAW 排版首选。
- **PNG (高清位图)**：支持 1x（标准）、2x（高清 200%）、4x（300DPI 印刷打印级）。
- **JPG / WebP**：标准纯白底色通用图与现代高压缩图片。
- **SVG + PNG 双格式合集**：自动在 ZIP 或本地目录中建立 `svg/` 与 `png/` 子目录分类存放。
- **智能清单附加**：自动生成带 UTF-8 BOM 的 `清单.csv`（Excel 打开绝不乱码，条码前置文本标记防变形）和 `清单.json`。

### 3. 批量打印与标签排版工作台
- **热敏卷筒标签纸**：支持 40×30mm、50×30mm、60×40mm、70×50mm、80×50mm、100×150mm 等标准单标连续走纸。
- **A4 不干胶拼版纸**：支持 A4-24联 (3×8)、A4-21联 (3×7)、A4-18联 (3×6)、A4-12联 (2×6) 等平张多格纸。
- **自定义规格**：可精确调整标签宽度、高度、拼版行数、列数、页面边距、标签间隙（mm）。
- **内容自由定制**：支持开关品名、条码数字、零售价格（`¥`）、自定义副标题/备注（如 `合格证`、`特级`），支持调节条码高度占比与手剪裁切虚线。
- **所见即所得即时预览**：真实毫米比例虚拟纸张渲染，支持多页翻页与 75% / 100% / 125% 缩放。
- **系统免驱动打印**：动态计算 `@page` 毫米级排版，调用系统打印机直接出纸或导出为标准 PDF。

### 4. 自动持久化与换机迁移
- **自动即时保存**：响应式深度监听所有 UI 参数与打印模板，无感实时保存至本地独立应用存储。
- **换电脑一键迁移**：点击顶部「⚙️ 备份/迁移」->「导出配置备份包」，在新电脑上一键导入即可全量恢复。

## 本地开发与构建

### 运行环境要求
- **Node.js** >= 18
- **pnpm** >= 9
- **Rust stable** 工具链 (MSVC on Windows)
- **Tauri 2 CLI**

### 安装依赖与启动开发
```bash
# 1. 安装依赖
pnpm install

# 2. 启动桌面端开发模式（支持热重载）
pnpm tauri dev

# 3. 仅启动前端浏览器预览
pnpm dev
```

### 构建打包
```bash
# 前端类型检查与打包
pnpm build

# 打包生成 Windows 独立 exe 及 NSIS 安装包
pnpm tauri build
```

打包产物位于 `src-tauri/target/release/bundle/nsis/条码工坊_0.1.1_x64-setup.exe`。

## 项目架构

```text
src/
  components/
    PrintModal.vue        # 批量打印与标签排版工作台组件
  utils/
    exporter.ts           # 多格式转换 (SVG/PNG/JPG/WebP)、ZIP 打包与 CSV/JSON 清单生成
    printer.ts            # 标签规格预设、分页算法与系统 @page 打印样式生成
  App.vue                 # 主工作台、批量生成、多选管理与导出面板
  styles.css              # 界面视觉设计、响应式布局与 @media print 隔离样式
  main.ts                 # Vue 应用入口
src-tauri/
  capabilities/           # Tauri 权限配置 (FS、Dialog、Opener)
  tauri.conf.json         # 桌面客户端窗口、打包格式与元数据配置
  src/
    lib.rs                # Tauri 插件与后端服务注册
```
